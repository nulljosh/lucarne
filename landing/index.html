Lucarne

A web browser is a text field and a WebKit view. Everything else is opinion.

SourceBuild it

What it does

One window, one page, an address bar, back, forward, reload, tabs. Mac, iPhone and iPad from one SwiftUI file. Type a host and it loads. Type words and it searches DuckDuckGo.

Rendering, JavaScript, cookies, gestures, autofill: WebKit already does all of it. Lucarne adds nothing on top until there is a reason to. No bookmarks, no sync, no telemetry.
